                                                   Balls and their admirers

This project is a C program that uses Raylib to create a simple animation with moving balls. The program creates 100 balls with random positions, velocities, sizes, and colors. Each ball is also assigned another ball to follow, so the balls move around the window while trying to move toward their chosen leader. The positions are updated continuously, and when a ball moves outside the window, it appears again from the opposite side. The animation runs in a 400x400 window until the user closes it.
